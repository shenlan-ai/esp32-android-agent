## Why
现有控制台同时展示连接、任务与模型表单，主次不清。用户要求全局安装 oil-ui、draw-ui，先使用指定图片 API / gpt-image-2.5 制作设计稿，再交付简约美观且保留真实功能的前端。

## What Changes
- 安全安装两个全局 UI skills，保留现有技能备份，记录来源版本。
- 先生成并检查设计稿，交付可追溯的设计说明与画面证据，密钥仅本机安全运行态使用。
- 改造静态网页为手机画面、任务工作区和次级设备/设置入口，保留中英文、状态与所有控制/固件流程。
- 完成响应式、键盘、错误/空态与真实模拟服务交互验证。

## Capabilities
### New Capabilities
- `console-presentation`: 简约控制台的布局、渐进展开、响应式与可访问性。
### Modified Capabilities
无。底层设备、模型、MCP及固件行为保持既有规格。

## Impact
静态 HTML/CSS/JavaScript、页面验证、设计产物。无新增产品运行依赖；不修改参考检出、不刷固件。第三方 API 仅用于本次设计生成，不修改用户执行模型配置。
