## Why
README 目前把手机笑脸截图放在首屏，无法突出更新后的控制台；视频也只有链接。用户要求展示更新后的前端效果（截图时手机保持常规画面）、直接在 README 内嵌视频，并新增一段通过 Codex MCP 设置闹钟的实机演示。

## What Changes
- 重新截取更新后的本地真实控制台作为README首屏，手机为常规主页/系统画面，移除旧DEMO与手机笑脸首屏。
- 上传授权演示MP4为GitHub附件，在英文、中文README直接显示实际可播放视频；保留仓库MP4回退，核验GitHub播放器。
- 通过 `android_agent` MCP 在同一实机上设置一个可验证的闹钟，录制原生屏幕视频，保存并重新打开闹钟确认。
- 完善 MCP 安装、Codex 注册、四个工具和安全调用顺序说明，补充闹钟演示的复现提示、设备条件和边界。

## Impact
仅文档、媒体及忽略目录临时录制工具；不改变产品协议、固件、依赖或前端行为，使用 `skip_specs: true`。手机输入通过 MCP + BLE，ADB 只用于截图、录屏和读取状态。闹钟属于用户授权的可逆手机设置；不会删除现有闹钟。
