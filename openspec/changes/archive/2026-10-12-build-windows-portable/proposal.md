## Why

用户运行源码需要 Python 环境，开源项目缺少可解压运行、可检查来源的 Windows 交付物。目前四个固件已经编译，发布工具却没有校验芯片、分区和产物来源。先建立便携应用、固件产物清单与解压验收流程，为后续刷写向导提供可靠输入。

## What Changes

- 构建 Windows x64 one-folder 应用，包含 Python、静态网页、许可、依赖版本、项目源码及四种固件；不会打包个人配置、参考检出或 Flash 备份。
- 启动器支持诊断、数据目录、旁置官方 Platform Tools；绑定成功后打开浏览器，端口冲突立即退出，不打开别人的页面。
- 固件收集器校验芯片头、分区、大小、地址和 SHA256；附构建对应的源码、第三方来源与用于重新链接的对象文件。
- 提供便携包真实子进程 smoke 测试，验证静态页面、API、缺 ADB 行为和端口冲突。ADB 不随包再分发，链接官方工具及放置步骤。

## Capabilities

### New Capabilities
- `portable-distribution`: 可检查来源的 Windows 便携应用和构建验证。

### Modified Capabilities
无。此变更不增加固件刷写行为；S3 通用刷写入口及网页安装向导将另立规格。

## Impact

服务入口、构建脚本、构建依赖、发布文档和测试。普通用户不需要 Node 或 Arduino 环境。PyInstaller 为开发构建依赖；构建工具运行在可信源码检出内。便携包仅作为本地产物，不上传发布，不再次覆盖 COM5。真实 Android 和 S3 输入验收仍待设备。
