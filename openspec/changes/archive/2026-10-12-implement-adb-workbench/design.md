# Design

## Context

遵循正式 product-foundation 与 project-governance。以已安装 Python 3.12 进行主验证，兼容 Python 3.10+；外部 ADB 不可用时也能启动配置界面。

## Goals / Non-Goals

**Goals:** 提供可运行的基础工作台和后续硬件、Agent 可复用边界。

**Non-Goals:** 本变更不声称自动任务或 ESP32 已可用，不建立自研投屏 App 或视频协议桥。

## Decisions

- server/android_agent 为独立包，应用 create_app + lifespan 管理会话和资源。相比模块级全局实例，可独立测试与清理。
- ADB 子进程使用本机参数列表，远端 shell 参数分别用 POSIX 引号转义；本机 shell=False 并不自动解决 adb shell 的远端注入。
- 会话操作锁串行化动作，停止通过代次编号作废排队动作并取消当前任务。ADB 滑动释放采取尽力 UP 注入，结果明确；硬件严格释放由后续协议实现。
- PNG 校验后保存真实尺寸，生成 JPEG 给模型；采集锁与短缓存避免预览请求积压。坐标端点映射到 width-1/height-1。
- 配置为 Pydantic 数据模型；显式提取密钥仅用于落盘与模型请求，更新留空保留原值。错误响应不带 Pydantic 输入原文。
- 本机 Host 校验与随机请求令牌防跨站操作，远程绑定另需访问令牌；静态网页不包含密钥。
- 网页围绕真实画面组织：左侧设备画面与停止，右侧连接、设置和任务状态。使用背景 #f1f5f8、正文 #183b56、操作 #006e68、辅助 #5b6b79、告警 #b52b37；系统 Segoe UI / 微软雅黑，不依赖外部字体或 npm。采用非等宽区域与轻量分隔，避免装饰卡片占据画面。

## Risks / Trade-offs

- ADB 截图性能因机型变化 → 按需与缓存控制，实测后决定视频升级。
- ADB 远端手势取消能力不同 → 限制时长并报告尽力释放结果，不声称所有机型立即停止。
- 控制期间切换设备 → 会话锁和代次校验，拒绝正在执行时切换。
