# Design

## Context

ADB 工作台正式规格已归档。用户要求最近三代安卓与常见板型。官方 Android 版本页现有 Android 17/API37 及 QPR 更新入口，兼容目标为 15–17；不把适配目标视为逐机型验收结果。

## Goals / Non-Goals

**Goals:** 有界且可观察的单步执行，独立结果判定，安全暂停与恢复。

**Non-Goals:** 不宣称模型验证必然正确；不硬编码供应商模型或价格；不调用未配置的云接口。

## Decisions

- ModelClient 通过 httpx 请求兼容 chat/completions，Base64 JPEG 图像与文本一起发送。保留配置的额外参数，关键消息结构不可覆盖。错误仅显示状态类别，不回显响应原文或凭据。
- JSON 解析只接受对象或完整 fenced JSON，拒绝重复键与多余正文。动作必须含预期结果；计划和验证分别有独立模型。
- TaskRunner 以单个受管理任务运行，暂停取消当前请求，完成释放后变为 paused；恢复新建模型客户端并重新规划，绑定设备保持一致。
- 执行前再次截图，tap/long_press 检查目标附近，其他动作检查整体；方向变化直接作废。执行后等待图像稳定，再用前后画面与预期做独立验证。
- 任务活动时间不计人工暂停时间；外层 wait_for 控制时限，输入不确定时暂停。失败重规划有上限，不重复发送同一结果未知输入。
- Token 使用供应商返回值；缺失时保守估算并标记。阈值用于停止后续请求，当前请求输入费用不能精确预知，不虚构硬性供应商账单限额。
- EventBus 有界队列，溢出发送重置提示，客户端重取快照。使用 fetch 流读取 SSE，兼容访问令牌头；不把令牌放进 URL。
- TraceStore 使用唯一任务目录、JSONL 记录和可选截图；导出 ZIP 只遍历合法任务目录。当前内存步骤图有界，清空释放内存而不删除历史。
- 设备会话用任务所有权阻止运行中的手动输入、切换和校准；暂停后允许手动输入及同一手机/控制路线的重连或重新校准，继续前再次核对绑定，不能把旧任务继续到另一手机。
- 最大模型调用数由动作和连续失败配置导出，不能只靠动作计数限制反复done/replan。请求有单次超时和1MB响应长度上限；失败/取消且缺少usage时记录保守估算及未确认调用数，不声称供应商账单硬上限。
- 模型动作JSON与Action共用参数验证；done/fail/replan单独严格对象，动作不得提供主机frame_id。最终目标核验由规划角色读取最新截图，单步结果核验读执行前后截图；规划未指定时共用执行模型但独立调用。
- 决策画面最大年龄60秒；模型返回后新取图比较几何和目标区域，执行时持有会话锁进行最终校验，网页预览历史淘汰不应让仍有效的内部决策误失效。变化后有限重新观察，不重放输入。稳定等待有界且报告实际稳定状态。
- 记录中的文本统一删除已知模型密钥及网页令牌；不记录模型响应原文、请求体或配置。当前步骤预览仅保留最近12张图，任务列表最多50项、当前步骤最多100项；导出拒绝目录/文件符号链接及越目录路径，限制导出大小。
- 网页通过带请求头的fetch读取SSE和图片/导出，令牌不进入URL；模型输出只用textContent显示。默认模型测试使用合成图片，不上传手机画面；模型调用只由明确运行任务或点击测试触发。
- 模型连接测试一次仅允许一个请求，进行中不能开始任务；停止和服务关闭会取消该测试并关闭客户端。网页轮询不能误启用仍在进行中的测试按钮。
- 网页提供可选额外JSON参数，保留供应商配置；若使用max_completion_tokens（64–4096），请求省略旧max_tokens字段，避免同时发送互斥输出限制。未确认请求用量估算包含该输出上限。

## Risks / Trade-offs

- 每步独立视觉验证增加请求耗时 → 首版优先正确性，用实际数据决定后续裁剪和缓存。
- 动画导致旧画面判断过严 → 目标区域比较与有限恢复，避免永久盲点。
- 模型返回缺失 usage → 明确估算状态，同时限制调用次数和时间。
- 多厂商兼容不可凭模拟测试证明 → 文档标记目标系统与待实机验证清单。
