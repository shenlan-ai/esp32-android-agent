# Describe MCP specification purpose

## Why
add-mcp-device-tools归档成功，但未在创建能力delta中提供Purpose，OpenSpec自动生成TBD目的；归档后strict校验因此失败。归档历史保持，另建文档变更补充正式规格目的。

## What Changes
将mcp-device-tools正式规格的Purpose占位句替换为该能力的真实用途；不修改Requirement/Scenario、实现、依赖或行为。

## Impact
仅正式规格目的及本变更元数据。无需额外软件或硬件测试；重新执行正式/归档strict校验、范围与空白检查。
