# 本机安卓控制台设计

北极星：像设备检查器一样安静，让真实手机画面和下一步操作成为主角。

用户打开页面先确认手机画面，再输入任务或手动操作。配置是开始前和维护时的工具，不占据每次操作的首页。桌面1440×900双栏、390×844单栏；生成画布1536×1024与CSS视口分别记录。

## 方向与取舍
比较了“设备检查器：浅色画布、画面与任务并列”和“终端实验台：深色画面、密集诊断”；选择前者，因为用户要求简约、美观且开源新用户需要可读的操作入口。借鉴Android Studio Device Mirroring的画面优先与Chrome DevTools的设置分离；未取得标杆实时画面，这些只作结构参考，不声明截图还原。最终以本项目生成图和真实页面检查配色、字体和比例。

颜色：背景#f5f6f8、表面#ffffff、文字#202632、次级文字#626b79、边界#e3e6ec、主动作#355de5。红色仅用于停止/危险/错误，绿色仅用于真实连接状态。强调色小面积使用。系统可用Segoe UI Variable / PingFang SC / Microsoft YaHei；不加载外部字体或框架。正文14px，标题24px，8px间距基准，控件10px圆角、主表面16px圆角，阴影仅用于整体层级。

布局：导航为工作台、设备连接、模型设置；手机画面始终挂载；右区切换任务/连接/模型面板。已有DOM ID与事件保留，面板隐藏不移除。窄屏导航改成横向具名入口，停止固定在顶栏，工作台按任务输入、手机画面、执行记录排序，长表单正常滚动。支持中英文。

动效：按钮按下1px回应（120ms），面板切换淡入与4px位移（180ms），首次工作区一次轻出场（260ms）；reduced-motion全部关闭。无循环装饰动画。

文字减法：移除首页长广告式标语，配置帮助进入对应面板；保留画面来源、控制方式、输入限制、固件覆盖和停止范围说明。保留所有固件/USB/校准说明的完整性。

素材分工：模型生成图是设计参考，不作为网页背景；布局、图标、文字、按钮由HTML/CSS实现，手机画面来自真实截图API。测试截图与模拟内容明确属于验收fixture，不代表实机结果。
