# 自动任务与人工接管

自动任务共用当前选择的ADB或ESP32控制方式，每次执行一个动作，然后读取新画面核验。开始前先在网页确认手机画面、手动点击和当前控制方式正常；BLE坐标操作需要保存当前手机与屏幕方向的鼠标校准。

## 配置模型

在“模型与运行设置”填写执行模型的API基础地址、视觉模型名称与可选密钥，保存设置。基础地址应包含供应商的API前缀，例如`https://api.example.com/v1`；程序在其后追加`/chat/completions`。本地兼容服务可以不填密钥。规划模型留空时共用执行模型配置，但规划和核验仍为独立调用。

“供应商可选参数”接受JSON对象，例如`{"temperature":0.1}`。支持使用`{"max_completion_tokens":2048}`替代默认的`max_tokens:1000`，该参数限制64–4096；不要同时使用供应商不支持的参数。请求消息、模型名与流设置由程序管理。

点击“测试模型”验证合成绿色图片请求。此步骤不上传手机画面，也不发送手机输入；停止可以取消测试。配置供应商是否接受请求，以及视觉判断是否准确，仍需实际验证。

模型接口使用[官方OpenAI视觉请求](https://developers.openai.com/api/docs/guides/images-vision)支持的Base64图片形式与兼容Chat Completions消息结构，JPEG按比例缩到最长1280像素，动作坐标覆盖完整截图的0–1000范围。

## 运行与核验

输入明确且可从画面确认的目标，例如“打开设置，进入 Wi-Fi 页面，告诉我开关状态”，点击“开始任务”。网页展示计划、动作说明、预期结果、输入耗时和画面证据。

首次任务可按 [可复现示例](EXAMPLES.md) 准备起始画面，以小预算测试只查看状态或不提交的ASCII输入。真实结果按 [验收模板](ACCEPTANCE.md) 记录，模型completed与人工观察分别判断；英文使用说明见 [English usage](USAGE.en.md)。

执行前重新截图，核对决策画面的年龄、尺寸和相关区域。旋转或目标区域显著变化时旧建议会被跳过并有限重新规划。决策画面超过60秒失效；较慢模型可能因此结束失败。

动作后的像素变化仅辅助等待稳定；结果还要经过独立视觉请求核验。模型提出done时，程序另取最新画面核验完整用户目标；未确认时继续有限恢复或失败，不直接标为完成。视觉模型仍可能误判，当前模拟验收不代表真实手机任务成功率。

## 暂停、停止与恢复

运行中手动输入、设备切换与校准被拒绝。点击“暂停并接管”后，等待状态变为“已暂停，可手动接管”，再手动操作。暂停会取消当前模型/动作请求并释放输入；已经提交的输入被取消时结果可能未知，记录会明确标注。

继续任务时重新观察并规划，不重放取消前的建议。暂停期间可在同一手机和同一控制路线重连、重新校准；更换手机或切换路线前先停止当前任务。

紧急停止或Esc结束任务，并返回实际释放状态。BLE未连接时只确认板上清理，不能确认手机收到释放报告。画面黑屏、受保护、手机或控制器断线时自动暂停；恢复连接、解锁或重新校准后再继续。

## 预算与记录

动作数、活动时间、连续失败和模型调用数均有限。人工暂停时间不计入任务活动时限；未确认输入仍计为一次已提交动作。

Token统计优先使用供应商返回的usage。缺失、失败或取消请求使用保守估算并标记；到阈值停止后续调用。当前请求的实际账单可能在返回前发生，阈值不是供应商账单的精确硬上限。项目不硬编码模型价格。

本机数据目录默认是用户目录下`.esp32-android-agent`，或`ANDROID_AGENT_DATA`指定位置。任务记录在`tasks/<任务ID>/`，包含JSONL事件和概要。已知模型密钥和网页访问令牌被删除，不写入记录。

“在本机保存任务截图”默认关闭。关闭时仍可查看当前任务最近12张内存步骤图，结束或清空后可能无法预览旧图；开启后执行前后图随记录落盘，可从ZIP导出。网页保留最近100项步骤，完整事件日志可以导出。“清空记录”只清空当前视图与内存，不删除本机历史；“本机任务记录”可查看与导出已有任务。

SSE断线或页面刷新后重新获取任务快照；任务在服务端继续，页面关闭不会自动停止任务。退出服务会取消请求并释放输入。

当前开发板刷写与串口验证已通过；真实手机输入、Android15–17机型兼容与真实模型供应商验收仍未完成，详见[兼容表](COMPATIBILITY.md)。
