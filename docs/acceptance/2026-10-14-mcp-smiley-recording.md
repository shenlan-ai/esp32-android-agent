## 实际输入与核验

全部10次手机输入均经原生 `android_action`，使用新的 `android_screenshot` 凭据并在动作后观察；3次circle、1次path、6次tap，全部返回ok。没有ADB、HTTP手动输入替代，不自动重放点击。

1. 在笔记列表点击新增，进入新笔记，点击绘图图标；开始录屏时是空白画布。
2. circle中心500/420、r180、duration_ms1500绘制轮廓；circle435/395、r16、450绘制左眼；circle568/395、r16、450绘制右眼。
3. 一次连续path绘制笑嘴：407/435 → 412/448 → 430/460 → 460/470 → 500/474 → 540/470 → 570/460 → 588/448 → 594/435，duration_ms1000。
4. 点击绘图完成，追加截图确认已进入保存后的笔记详情；结束录像。
5. 通过MCP返回列表，确认顶部是新笔记缩略图，重新打开该笔记；追加截图确认同一笑脸保留。最后点击绘图外的空白处移开指针，画面保持笔记详情。
6. 调用android_stop，返回`hid_release_sent`、`firmware_in_progress=false`；本次两次停止均返回相同释放状态。之后只读高分辨率截图，未修改笔记。

本次页面切换后多次第一张截图仍显示前页，追加观察后确认新页面，没有据此重复点击。没有误入其他笔记或被拒绝的手机动作。准备阶段有一次错误CSRF头导致配置请求403，以及一次机型名称断言不匹配（系统返回型号代码）；均在手机输入前修正，不改动产品、不绕过校验。
